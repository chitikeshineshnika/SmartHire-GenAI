## Skill roadmap

### 1. Prerequisites and foundations

- Core concepts: cloud fundamentals, networking, compute, storage and databases, security basics, and design principles such as scala

- Programming and scripting: Python, Bash or PowerShell, and reading YAML and JSON.

- Development environment: Git, a cloud account for practice, and diagramming tools for architecture drawings.

- Switching from another field: cloud engineers, DevOps engineers, network engineers and developers with several years of hands-on ex

### 2. Core and technical skill progression

- Level 1, fundamentals: one cloud platform's core services and an entry-level certification (AWS Cloud Practitioner, Azure Fundament

- Level 2, core competencies: associate-level skills to design, deploy and manage secure, scalable applications (AWS Solutions Archit

- Level 3, advanced: architecture patterns and system design, cost optimization, multi-cloud and hybrid strategies, migration plannin

### 3. Practical tooling and ecosystem

- Platforms: AWS, Azure, Google Cloud, Oracle Cloud.

- Infrastructure as Code: Terraform, Pulumi, Ansible, CloudFormation.

- Design guidance: the Well-Architected frameworks of AWS, Azure, Google Cloud and Oracle Cloud.

- Security: IAM, key management, network controls.

### 4. Hands-on projects and portfolio milestones

- Beginner: design and deploy a three-tier web app on one cloud.

- Intermediate: an architecture diagram with a written justification for scalability, availability and cost, built with Infrastructur

- Advanced: a multi-region, highly available architecture with a migration plan, a cost estimate and a security and compliance review
