## Skill roadmap

### 1. Prerequisites and foundations

- Core concepts: programming fundamentals, data structures and algorithms, how computers and operating systems work at a basic level,

- Programming: at least one general-purpose language such as Python, Java, JavaScript, C++ or C#, and SQL.

- Development environment: Git and GitHub, an IDE or editor, the command line, a debugger.

- Years per level differ between sources and companies, and smaller companies often use fewer levels: junior, mid, senior and lead.

### 3. Practical tooling and ecosystem

- Languages and frameworks: depend on the path (see the frontend, backend, full stack and mobile notes).

- Databases: PostgreSQL or MySQL, and a NoSQL option such as MongoDB.

- DevOps: Docker, CI with GitHub Actions or similar, a cloud platform, logging and monitoring.

- Industry knowledge also helps: a developer in a bank benefits from understanding finance.

### 4. Hands-on projects and portfolio milestones

- Beginner: command-line tools, small apps, algorithm practice, and a first web app.

- Intermediate: an end-to-end application with a database, an API and tests, plus contributions to a shared codebase.

- Advanced: a system with design documents, scalability and monitoring, and mentoring or reviewing others' work.
