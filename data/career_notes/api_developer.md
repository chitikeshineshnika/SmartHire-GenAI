## Skill roadmap

### 1. Prerequisites and foundations

- Core concepts: how HTTP works (methods, headers, status codes), client and server, JSON, how databases store data, basic security i

- Programming: one backend language (Python, Java or JavaScript) and SQL.

- Development environment: Git and GitHub, Postman or a similar API testing tool, VS Code or an IDE, the command line.

- Switching from another field: testers and frontend developers already know part of this. Start by calling public APIs, then build y

### 2. Core and technical skill progression

- Level 1, fundamentals: REST principles, routing, CRUD operations, request validation, correct status codes, JSON responses, and tes

- Level 2, core competencies: authentication and authorization (API keys, tokens, OAuth basics), pagination and filtering, error hand

- Level 3, advanced: API gateways, communication between services (microservices), alternatives such as GraphQL and gRPC, caching, ba

- Rough guide to experience: Level 1 matches 0 to 2 years of work, Level 2 about 2 to 5 years, Level 3 about 5 years and beyond.

### 3. Practical tooling and ecosystem

- Frameworks: FastAPI, Flask or Django REST Framework; Spring Boot; Express.

- Documentation and testing: OpenAPI or Swagger, Postman, automated test frameworks (pytest, JUnit, Jest).

- Databases: PostgreSQL or MySQL, Redis for caching.

- Infrastructure: API gateways, Docker, CI pipelines, cloud platforms.

### 4. Hands-on projects and portfolio milestones

- Beginner: a notes or to-do API, and a script that consumes a public API.

- Intermediate: a blog or e-commerce API with login, roles, validation, documentation and tests.

- Advanced: an API with rate limiting, versioning, caching and monitoring, load tested and deployed with CI.
