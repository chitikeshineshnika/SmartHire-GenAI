## Skill roadmap

### 1. Prerequisites and foundations

- Core concepts: product metrics (funnels, retention, cohorts, engagement, lifetime value), statistics (hypothesis testing, confidenc

- Programming: SQL, then Python or R.

- Development environment: Excel or Google Sheets, Jupyter Notebook, a BI tool, and Git basics.

- Switching from another field: marketing, operations or business analysts can add SQL, statistics and experimentation.

### 2. Core and technical skill progression

- Level 1, fundamentals: SQL, Excel, basic data visualization, defining metrics, attention to detail.

- Level 2, core competencies: advanced SQL, funnel analysis (where users drop off), cohort retention analysis (whether users stay), A

- Level 3, advanced: experimentation strategy and quasi-experiments, segmentation, regression and causal inference, setting standards

- A common trap: testing many metrics at once increases the chance of a false positive, so decide the main metric in advance.

### 3. Practical tooling and ecosystem

- SQL and data warehouses for user-level product data.

- Python or R for statistics and analysis.

- BI tools: Tableau, Looker, Power BI.

- Experimentation and product analytics tools (the specific platform depends on the company).

### 4. Hands-on projects and portfolio milestones

- Beginner: a funnel analysis in SQL on a public e-commerce dataset.

- Intermediate: a cohort retention analysis and a retention dashboard, and an A/B test analysis with a written recommendation.
