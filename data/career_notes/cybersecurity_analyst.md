### 2. Core and technical skill progression

- Level 1, fundamentals: IT and networking basics, operating systems, security concepts, and reading logs such as Windows event logs

- Level 2, core competencies: SIEM tools (Splunk, QRadar, Microsoft Sentinel, and open-source ones such as Wazuh or Security Onion),

- Level 3, advanced: tuning detections and reducing false positives, threat intelligence, leading incident response, digital forensic

### 3. Practical tooling and ecosystem

- SIEM: Splunk, IBM QRadar, Microsoft Sentinel, Wazuh, Security Onion.

- Endpoint and network: CrowdStrike, SentinelOne, Snort, Suricata, firewalls, Wireshark.

- Skills used daily: log analysis, identity and access concepts, ticketing and report writing.
