## Skill roadmap

### 1. Prerequisites and foundations

- Core concepts: how LLMs work at a practical level (tokens, context windows, temperature, embeddings), APIs and JSON, basic machine

- Programming: Python, plus software engineering essentials such as testing, version control and API design.

- Development environment: Git and GitHub, VS Code, Jupyter, Docker, and secure handling of API keys.

- Switching from another field: developers have the biggest head start. A rough guide from one roadmap is 2 to 3 months for software

### 2. Core and technical skill progression

- Level 1, fundamentals: calling LLM APIs, prompt engineering (templates, structured JSON output, testing and versioning prompts), an

- Level 2, core competencies: RAG (chunking, embeddings, vector databases, retrieval, reranking), orchestration with LangChain or Lla

- Level 3, advanced: agents that use tools and complete multi-step tasks (still an experimental area), orchestration, LLMOps (logging

- Durable skills such as programming, system design, testing and deployment stay valuable even when specific tools change.

### 3. Practical tooling and ecosystem

- LLM APIs: OpenAI, Anthropic Claude, Google Gemini and open-source models.

- Frameworks: LangChain, LlamaIndex.

- Vector databases: FAISS, Chroma, Pinecone, Weaviate, pgvector.

- Evaluation and observability: RAGAS, TruLens, LangSmith.

- Interfaces and deployment: Streamlit, FastAPI, Docker, and cloud platforms such as AWS Bedrock or Azure AI Studio.

### 4. Hands-on projects and portfolio milestones

- Beginner: a chatbot with well-designed prompts, a resume parser that returns structured JSON.

- Intermediate: a PDF chatbot with RAG, a customer-support RAG assistant, and an AI app with a Streamlit interface.

- Advanced: a tool-using agent, a RAG system with hybrid search, reranking and measured evaluation, a text-to-SQL app with guardrails
