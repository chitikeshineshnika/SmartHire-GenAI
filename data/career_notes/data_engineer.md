### 3. Practical tooling and ecosystem

- Orchestration and transformation: Apache Airflow, dbt, AWS Glue, Azure Data Factory.

- Processing and streaming: Apache Spark, Kafka.

- Warehouses and storage: Snowflake, BigQuery, Redshift, S3, GCS, Azure Blob, PostgreSQL.

- Cloud and DevOps: AWS, GCP or Azure, Docker, CI pipelines.

- Certifications often named: Google Cloud Professional Data Engineer and Azure Data Engineer Associate.
