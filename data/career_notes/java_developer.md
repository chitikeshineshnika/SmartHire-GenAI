### 3. Practical tooling and ecosystem

- Frameworks: Spring Boot, Spring MVC, Spring Security, Hibernate. JSP and Servlets appear mainly in older applications.

- Databases: MySQL, PostgreSQL or Oracle for relational data, MongoDB for NoSQL, Redis for caching.

- DevOps and cloud: Docker, Jenkins or GitHub Actions, Kubernetes, and a cloud platform (AWS, Azure or GCP).

- Frontend pairing for full stack roles: React or Angular.
