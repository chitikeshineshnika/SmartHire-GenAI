# Business Intelligence Analyst and Reporting Analyst

## Role guide

A BI analyst turns raw data into reports, dashboards and performance views that support business decisions. They usually own the repo

## Skill roadmap

### 1. Prerequisites and foundations

- Core concepts: KPIs and metric definitions, data modeling basics (tables, keys, relationships, star schema), data quality, basic st

- Programming: SQL. Python is a plus.

- Development environment: Excel, Power BI Desktop (or Tableau), a SQL client, a data dictionary for documentation.

- Switching from another field: finance, operations and sales professionals already know the business metrics. Add SQL and a BI tool

### 3. Practical tooling and ecosystem

- BI tools: Power BI (with Power Query and DAX), Tableau, Looker.

- Data: SQL, Excel, data warehouses (for example Snowflake, BigQuery, Azure Synapse).

- Certification often named: Microsoft PL-300, Power BI Data Analyst Associate.

- Plus points in job posts: Python and cloud-based data management.

- Intermediate: a Power BI sales dashboard built on a star schema with DAX measures, and a churn or retention report.
