# Frontend Developer

## Role guide

A frontend developer builds the part of a website or web application that users see and interact with: pages, menus, forms and animat

## Skill roadmap

### 1. Prerequisites and foundations

- Core concepts: how the web works (client and server, HTTP, browsers, URLs), basic design and usability ideas, accessibility basics,

- Programming: HTML, CSS and JavaScript. These three are the base of all frontend work.

- Development environment: Git and GitHub, VS Code, browser developer tools, basic command line, npm.

- Switching from another field: the same foundations apply. Your earlier domain knowledge (finance, retail, healthcare) helps you und

### 2. Core and technical skill progression

- Level 1, fundamentals: semantic HTML, forms, CSS layout with Flexbox and Grid, responsive and mobile-first design, JavaScript basic

- Level 2, core competencies: a framework (React is the most commonly listed; Vue and Angular are alternatives), components, hooks, r

- Level 3, advanced: frontend architecture for large apps, server-side rendering and frameworks such as Next.js, performance tuning,

- Rough guide to experience: Level 1 matches the first 0 to 2 years of work, Level 2 about 2 to 5 years, and Level 3 about 5 years an

### 3. Practical tooling and ecosystem

- Libraries and frameworks: React, Next.js, Tailwind CSS, a state library such as Redux or Zustand, Vue or Angular as alternatives.

- Build tools: npm, Vite or webpack.

- Data: frontend developers mostly consume REST or GraphQL APIs and use browser storage. Firebase is a common easy backend for projec

- Deployment and quality: Netlify or Vercel for hosting, GitHub Actions for CI, Lighthouse for performance checks, and an error track

### 4. Hands-on projects and portfolio milestones

- Beginner: personal portfolio, to-do app, landing page clone, weather app that calls a public API.

- Intermediate: a React app with routing, login screens and API calls, such as a blog, movie search or e-commerce interface, with tes

- Advanced: a production-style app with Next.js, TypeScript, a design system, performance and accessibility reports, and a CI pipelin
