## Skill roadmap

### 1. Prerequisites and foundations

- Core concepts: Linux, networking, cloud fundamentals, how developers work (build, test, deploy, operate), and product thinking.

- Programming: Python, Go or TypeScript and JavaScript for internal tools and portals.

- Development environment: Git and GitHub, Docker, the terminal, a cloud account.

- Switching from another field: DevOps engineers, SREs and senior developers are the usual entrants.

### 2. Core and technical skill progression

- Level 1, fundamentals: the DevOps basics: Linux, Git, Docker, CI/CD pipelines and one cloud platform.

- Level 2, core competencies: Kubernetes and the wider CNCF ecosystem, Infrastructure as Code with Terraform, GitOps with ArgoCD or F

- Level 3, advanced: building an internal developer platform (IDP) with a developer portal such as Backstage, including custom plugin

### 3. Practical tooling and ecosystem

- Developer portals: Backstage, Port.

- Delivery: ArgoCD, Flux, Argo Rollouts, Helm, GitHub Actions.

- Infrastructure: Kubernetes, Terraform, Crossplane, managed Kubernetes services (EKS, GKE).

- Observability: Prometheus, Grafana.

- Intermediate: GitOps deployment of several services with ArgoCD from a Git repository.
