## Skill roadmap

### 1. Prerequisites and foundations

- Core concepts: data warehousing concepts, business context and KPI definitions, and how data analysts use data.

- Programming: SQL mastery first. Python helps with APIs, orchestration and testing, but most modeling work is still SQL.

- Development environment: Git and GitHub, the command line, VS Code, and a warehouse console.

- Switching from another field: data analysts and BI developers have strong transferable skills (SQL, dashboards, KPI definitions). W

### 2. Core and technical skill progression

- Level 1, fundamentals: advanced SQL, understanding the grain of a table, dimensional modeling (Kimball style), and warehouse basics

- Level 2, core competencies: dbt (models, sources, Jinja, tests, documentation), version control, building tested and documented mod

- Level 3, advanced: semantic layers, data quality and observability, CI/CD for data models, handling schema changes and data contrac

- A suggested sequence in guides: SQL, then data modeling, then tested and documented projects.

### 3. Practical tooling and ecosystem

- Transformation: dbt and SQL (primary).

- Warehouses: Snowflake, BigQuery, Databricks SQL.

- BI: Looker, Power BI, Tableau.

- Quality and orchestration: dbt tests, data quality tools, Airflow.

- Certifications named in guides: dbt Fundamentals and dbt Analytics Engineering.

### 4. Hands-on projects and portfolio milestones

- Beginner: SQL models on a sample warehouse dataset.

- Intermediate: an e-commerce dbt project with dimensional models for orders, customers and products, with tests and documentation.

- Advanced: a data quality framework with custom tests and monitoring, or a migration of a legacy SQL reporting layer into dbt with C
