# Penetration Tester (Ethical Hacker)

## Role guide

A penetration tester is an ethical hacker who is authorized to attack systems, applications and networks in order to find weaknesses

## Skill roadmap

### 1. Prerequisites and foundations

- Core concepts: networking (you cannot test what you do not understand), Linux (non-negotiable for this role), operating system secu

- Programming: Python for scripting and automation, plus Bash.

- Development environment: Kali Linux, virtual machines, and legal practice labs such as TryHackMe and Hack The Box. Only test system

- Switching from another field: SOC analysts, system administrators, network engineers and developers move across most easily.

### 2. Core and technical skill progression

- Level 1, fundamentals: networking and Linux, security basics, an entry certification such as CompTIA Security+, and guided beginner

- Level 2, core competencies: web application security (the OWASP Top 10, Burp Suite, OWASP ZAP), network scanning with Nmap, exploit

- Level 3, advanced: the OSCP, a hands-on certification that is widely respected because it is a practical exam and not multiple choi

### 3. Practical tooling and ecosystem

- Core tools: Kali Linux, Nmap, Burp Suite (it appears in a large share of job postings), Metasploit, Wireshark, OWASP ZAP, password

- Practice platforms: TryHackMe, Hack The Box, deliberately vulnerable web apps.

- Skills around the tools: scripting in Python, note-taking and clear reporting.

### 4. Hands-on projects and portfolio milestones

- Beginner: complete guided lab paths and keep notes on every machine.

- Intermediate: solve CTF challenges and write up each one, and test an intentionally vulnerable web application in your own lab.
