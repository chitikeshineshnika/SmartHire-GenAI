## Skill roadmap

### 1. Prerequisites and foundations

- Core concepts: programming basics, object-oriented programming, data structures, how the web works (HTTP, requests and responses),

- Programming: Python and SQL.

- Development environment: Git and GitHub, VS Code or PyCharm, virtual environments and pip, the command line.

- Switching from another field: Python is a common first language, so start with the basics, build scripts that solve a real problem,

### 2. Core and technical skill progression

- Level 1, fundamentals: syntax, data types, functions, files and exceptions, object-oriented Python, modules and the standard librar

- Level 2, core competencies: a web framework (one guide suggests Flask basics first, then Django or FastAPI), REST APIs, routing, vi

- Level 3, advanced: asynchronous programming and the difference between WSGI (Django, Flask) and ASGI (FastAPI), background tasks, c

- Rough guide to experience: Level 1 matches 0 to 2 years of work, Level 2 about 2 to 5 years, Level 3 about 5 years and beyond.

### 3. Practical tooling and ecosystem

- Frameworks: Django with Django REST Framework, Flask, FastAPI.

- Databases: PostgreSQL or MySQL, SQLAlchemy, Redis for caching.

- DevOps and cloud: Docker, GitHub Actions, a cloud platform, and Nginx for production serving.

- Data libraries when needed: pandas, NumPy.

- Choosing a framework: Flask for small apps and microservices, Django for full web apps, FastAPI for new, high-performance APIs.

### 4. Hands-on projects and portfolio milestones

- Beginner: command-line tools, automation scripts, a small Flask app.

- Intermediate: a blog or learning management system with login, a database and tests, plus a REST API with FastAPI or Django REST Fr

- Advanced: a deployed multi-service application with background jobs, caching, containers and CI, with a short architecture write-up
