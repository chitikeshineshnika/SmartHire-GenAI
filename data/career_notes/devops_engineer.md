# DevOps Engineer

## Role guide

A DevOps engineer connects software development and operations. They automate how software is built, tested, deployed and monitored,

## Skill roadmap

### 1. Prerequisites and foundations

- Core concepts: how software moves from code to production, networking basics (DNS, IP, SSH), and the Linux operating system.

- Programming: Bash for quick automation, and Python for DevOps scripting and working with APIs.

- Development environment: Git and GitHub (branching, merging, pull requests), the terminal, VS Code.

- Switching from another field: system administrators, developers and testers have a head start. People from non-IT backgrounds also

### 2. Core and technical skill progression

- Level 1, fundamentals: Linux and shell scripting, Git, the basics of one cloud platform (virtual machines, storage, IAM, networking

- Level 2, core competencies: CI/CD pipelines with Jenkins, GitHub Actions or GitLab CI, Kubernetes fundamentals, Infrastructure as C

- Level 3, advanced: Helm and GitOps with ArgoCD, DevSecOps (scanning in the pipeline, secrets management), observability (metrics, l

### 3. Practical tooling and ecosystem

- Version control and CI/CD: Git, Jenkins, GitHub Actions, GitLab CI.

- Containers: Docker, Kubernetes, Helm.

- Infrastructure as Code: Terraform, Ansible, CloudFormation.

- GitOps: ArgoCD or Flux.

- Monitoring: Prometheus, Grafana, ELK stack.

- Cloud platforms: AWS, Azure, GCP.

- Certifications often named: Certified Kubernetes Administrator (CKA), HashiCorp Certified Terraform Associate, and associate-level
