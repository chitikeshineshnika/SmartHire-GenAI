## Skill roadmap

### 1. Prerequisites and foundations

- Core concepts: linear algebra, basic calculus and probability, how digital images are represented, and machine learning fundamental

- Programming: Python with NumPy. C++ is useful for performance-critical roles such as embedded or real-time systems.

- Development environment: Git and GitHub, Jupyter or Colab, OpenCV, and GPU access (many free notebook services offer it).

- Switching from another field: software developers and data scientists can add computer vision by learning image processing and a de

### 2. Core and technical skill progression

- Level 1, fundamentals: image input and output, filters and transformations, drawing, contours, edge and corner detection with OpenC

- Level 2, core competencies: deep learning with PyTorch or TensorFlow (choose one), convolutional neural networks, image classificat

- Level 3, advanced: multi-object tracking (SORT, DeepSORT, ByteTrack), 3D vision, OCR, video AI, vision transformers and foundation

### 3. Practical tooling and ecosystem

- Libraries: OpenCV, PyTorch, TensorFlow, scikit-image, Pillow.

- Models: the YOLO family, Faster R-CNN, U-Net, Mask R-CNN.

- Deployment: ONNX and quantization for speed, Docker, FastAPI, GPU toolkits from NVIDIA, edge devices.

- Learn PyTorch well and practise implementing research papers.

### 4. Hands-on projects and portfolio milestones

- Beginner: edge and contour detection tool, a face mask detection system, lane detection from video.

- Intermediate: a CNN image classifier with transfer learning, and an object detection project with a custom dataset.
